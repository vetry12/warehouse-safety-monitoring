# Warehouse Safety Monitoring System

A real-time AI system that detects workplace safety violations from live camera feeds using deep learning.

## Project Overview

Final year B.Tech (AI & ML) project — building a computer vision pipeline that automatically identifies:

- Workers not wearing helmets
- Workers not wearing safety vests
- Workers entering unauthorized zones

## Tech Stack

- **Language:** Python 3.11
- **Deep Learning:** PyTorch (CUDA), Ultralytics YOLOv8
- **Computer Vision:** OpenCV
- **Tracking:** DeepSORT
- **Dashboard:** Streamlit
- **Database:** SQLite

## Hardware

Developed and tested on a laptop with NVIDIA RTX 3050 (4 GB VRAM), 16 GB RAM.
